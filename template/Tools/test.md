# Tools — Test

| ID | Comando / ação | Notas |
|----|----------------|-------|
| `dotnet.test` | `dotnet test` | Preferir testes da feature |
| `node.test` | `npm test` / equivalente | Preferir paths da feature |
| `flutter.test` | `flutter test <path>` | Preferir paths da feature |
| `test.custom` | script do projeto | Documente o comando aqui |

Registre sempre o ID e o resultado no LOG da run.
