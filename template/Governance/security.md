# Governance — Security

## Regras base

- Não commitutar secrets, credentials ou chaves.
- Não logar tokens, PII ou payloads sensíveis.
- Respeitar classificação de dados da organização.
- Dependências novas: avaliar CVE / licença conforme processo da empresa.

## IA

- Sem enviar dados sensíveis a provedores externos sem autorização.
- Guardrails de entrada/saída quando a feature usar modelo.
- Decisões críticas com aprovação humana (`ask`).
